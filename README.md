# Mastering Kotlin Multiplatform — companion code

Companion code for *Mastering Kotlin Multiplatform* by WANKAM Dypue Dilane Junior (2026).

All projects (Hearthseed, Mendfield and the chapter examples) are fictional and original.
Every key or token in this repository is a fictional placeholder (`YOUR_...`).

Continuous integration builds and tests the code on Linux (JVM, Android, Desktop, JS, Wasm)
and on macOS with Xcode (Kotlin/Native iOS tests and the SwiftUI apps).

`toolchain-check/` is a minimal project that validates the version set used in the book.
